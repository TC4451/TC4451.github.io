# tc4451.github.io

Personal academic homepage of Zilin Dai, built with [academic-homepage](https://github.com/luost26/academic-homepage).

- Profile, education, experience, awards: `_data/profile.yml`
- Publications: `_publications/<year>/*.md` (set `selected: true` to show on the homepage)
- News: `_news/*.md`
- Patents: `_data/patents.yml`

Local preview: `bundle install && bundle exec jekyll serve`
