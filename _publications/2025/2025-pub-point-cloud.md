title:          "A Strong View-Free Baseline Approach for Single-View Image Guided Point Cloud Completion"
date:           2025-06-18 00:01:00 +0800
pub:            "arXiv preprint"
pub_date:       "2025"

abstract: >-
  Single-view image guided point cloud completion reconstructs a complete point cloud from a partial input with the help of a single-view image, but whether the image guidance is fundamentally necessary remains largely unexamined. We propose a strong view-free baseline: an attention-based multi-branch encoder-decoder with a hierarchical self-fusion mechanism that takes only partial point clouds as input, and outperforms state-of-the-art image-guided methods on ShapeNet-ViPC.
